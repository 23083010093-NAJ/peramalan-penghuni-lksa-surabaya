# Peramalan Jumlah Penghuni LKSA Surabaya

Repository ini disiapkan sebagai kerangka proyek analisis dan peramalan jumlah penghuni Lembaga Kesejahteraan Sosial Anak (LKSA) di Kota Surabaya.

## Tujuan Umum
Menyediakan ruang kerja terstruktur untuk pengelolaan data, analisis deret waktu, pemodelan peramalan, evaluasi, dan dokumentasi hasil penelitian.

## Teknologi
- Python 3.11
- Visual Studio Code
- Jupyter Notebook
- Git dan GitHub
- Pandas dan NumPy
- Matplotlib
- Statsmodels
- Jupyter dan IPykernel

## Struktur Repository
```text
peramalan-penghuni-lksa-surabaya/
```

Direktori disediakan untuk pengembangan bertahap. File analisis dan implementasi setiap progress akan ditambahkan setelah tahap terkait dikerjakan.

## Instalasi
Persyaratan: Python 3.11 dan Git.

Buat virtual environment:

```powershell
python -m venv .venv
.venv\\Scripts\\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```
