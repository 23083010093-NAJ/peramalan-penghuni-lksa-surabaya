# Program dan Teknologi

## Perangkat lunak
| Program | Kegunaan |
|---|---|
| Python 3.11 | Bahasa pemrograman utama |
| Visual Studio Code | Editor kode dan terminal |
| Jupyter Notebook | Analisis interaktif dan dokumentasi eksperimen |
| Git | Version control |
| GitHub | Hosting repository dan kolaborasi |

## Pustaka Python
| Pustaka | Kegunaan |
|---|---|
| Pandas | Pembersihan, transformasi, dan manipulasi data |
| NumPy | Komputasi numerik |
| Matplotlib | Visualisasi data |
| Statsmodels | Analisis deret waktu, uji ADF/KPSS, dan model statistik |
| Jupyter | Menjalankan notebook |
| IPykernel | Kernel Python untuk Jupyter |

## Instalasi
```powershell
python -m venv .venv
.venv\\Scripts\\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Daftar pustaka menggambarkan kebutuhan umum project starter. Versi paket belum dikunci sebagai environment reproducible.
