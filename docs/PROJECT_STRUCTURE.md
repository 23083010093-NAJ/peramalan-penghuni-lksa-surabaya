# Struktur Proyek

| Direktori | Tujuan |
|---|---|
| data/raw/ | Menyimpan data sumber asli |
| data/processed/ | Menyimpan data hasil pembersihan atau transformasi |
| docs/ | Dokumentasi, metodologi, dan panduan |
| notebooks/ | Notebook analisis |
| src/ | Kode sumber proyek |
| tests/ | Pengujian kode |
| output/ | Grafik, tabel, dan hasil analisis |

Direktori disiapkan untuk pengembangan bertahap. Folder tanpa file belum tampil pada GitHub; tambahkan file README.md atau file proyek ketika direktori mulai digunakan.
