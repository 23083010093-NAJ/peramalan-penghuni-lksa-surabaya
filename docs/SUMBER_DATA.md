# Sumber Data

**Nama dataset:** Banyaknya Panti Asuhan, Kapasitas dan Penghuni Per Kecamatan  
**Instansi sumber:** Dinas Sosial Kota Surabaya  
**Portal resmi:** [Satu Data Surabaya — detail dataset](https://ckan.surabaya.go.id/id/dataset/banyaknya-panti-asuhan-kapasitas-dan-penghuni-per-kecamatan)  
**Nama file sumber:** `07-panti-asuhan-per-kecamatan.csv`  
**Lokasi yang disiapkan:** `data/raw/07-panti-asuhan-per-kecamatan.csv`

File CSV yang digunakan secara lokal menjadi titik awal analisis. Periksa halaman resmi untuk metadata, resource, rentang waktu, definisi kolom, dan ketentuan penggunaan yang berlaku.

Tanggal pengunduhan file belum terdokumentasi. Saat mengganti atau memperbarui file, catat tanggal pengunduhan, URL resource, rentang data, perubahan skema, satuan, dan informasi lisensi/atribusi yang tersedia pada portal.

Jangan menganggap lisensi repository untuk kode (apabila kelak ditambahkan) otomatis berlaku terhadap dataset pihak ketiga. Pastikan ketentuan penyedia data mengizinkan redistribusi sebelum mengunggah atau membagikan salinan dataset.
