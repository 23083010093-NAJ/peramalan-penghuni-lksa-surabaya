# Source Code

## Implementasi yang sudah tersedia
- `progress_1_eksplorasi_stasioneritas.py`: validasi data, penghapusan duplikasi identik, agregasi bulanan, visualisasi, first difference, serta uji ADF dan KPSS.
- `_common.py`: fungsi bersama untuk membaca, memvalidasi, membersihkan, dan mengagregasikan data serta menjalankan uji stasioneritas.

Jalankan dari direktori utama repository:

```powershell
python src/progress_1_eksplorasi_stasioneritas.py
```

Progress selanjutnya akan menambahkan modul terpisah secara bertahap.
